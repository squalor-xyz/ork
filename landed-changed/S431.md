A self-host project that sets `ork projects set NAME --auto-rebuild on` now has a daemon that rebuilds and restarts itself after a landing that leaves it behind main. It holds new role starts, lets running roles finish (none is killed), builds, and starts the rebuilt daemon. A failed build, or a build that leaves the daemon's own executable at the old revision, keeps the old daemon and shows `daemon not rebuilt` with the reason and output lines. A held run shows `waiting for daemon rebuild`. Off by default; `ork daemon restart --rebuild` is unchanged.

Retrying a stopped run that held review, architect, gate or owner findings now starts an implementer fix round that carries them, instead of re-entering the checks and dropping them. A retry also resets the gate FAIL count, so a run stopped by its third gate FAIL is no longer stopped again by its first FAIL after the resume. A red-check or no-feedback stop still re-enters the checks. The start message of ork run names the path it took.

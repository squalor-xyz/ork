Implementer presets and the built-in default now allow git ls-files, git mv, git rm and non-recursive rm (adj 478). The approval hook denies a removal outside the worktree and never grants a recursive rm through the plain rm entry. Cloud Claude write roles now run the approval hook too, but only to deny outside paths, a recursive rm and a removal it cannot check; every other call is left to the CLI's own allowlist, with no owner questions and no Read cap. Cloud roles also get recursive rm deny rules. Projects that store a list pick up the new entries with ork projects set NAME --preset go|python, or with --allow implementer=PATTERN.
